# FileMate A4 前端可靠性验收

> 验收分支：`codex/a4-ui-reliability`
>
> 验收范围：Vue 3 开发页面 + 本地 FastAPI，桌面 1440×900 与移动端 375×812
>
> 数据口径：匿名 TXT 样本，不依赖真实课件或外部 API Key

## 用户主链

已通过真实浏览器完成以下流程：

1. 导入匿名 TXT 资料；
2. 上传完成后显示“审核结果”，进入带 `session` 参数的分类页面；
3. 保存分类后自动进入命名确认；
4. 确认命名并执行可信归档；
5. 在处理记录中查看结果并撤销归档；
6. 文件恢复到托管上传目录，页面状态更新为“已完成”。

## 本轮修复的真实阻塞

- 补齐 Vite 对 `/review`、`/study-plans`、`/evaluation` 的后端代理；
