# 流程 4 验收：出题 → 作答 → 错题 → 今日复习 → 掌握

> 验收日期：2026-08-17
> 基线：`main` = `004aa4c`（含 A1 统一题目主链）
> 执行人：杨乐
> 方式：API 闭环验收（FastAPI TestClient + 临时 SQLite），不依赖真实 LLM

## 验收目标

验证 A1 合入后，“生成题目 → 提交答案 → 答错进错题本 → 今日复习 → 连续答对掌握”的完整闭环。

## 验收步骤

1. 在临时数据库创建一道题目 Artifact。
2. 提交错误答案：
   - 预期：判为错误，自动进入错题本。
3. 查询 `/wrongbook?mastered=false`：
   - 预期：包含该题。
4. 查询 `/review/today`：
   - 预期：今日复习队列包含该错题。
5. 连续两次提交正确答案：
   - 第一次：正确，但仍在待复习错题中。
   - 第二次：正确，自动标记为已掌握。
6. 查询 `/wrongbook?mastered=true` 和 `mastered=false`：
   - 预期：已掌握列表包含该题，待复习列表为空。

## 验收结果

| 步骤 | 结果 |
|---|---|
| 提交错误答案 | 通过，`is_correct=false`，提示已加入错题本 |
| 答错后错题本 | 通过，包含该题 |
| 答错后今日复习 | 通过，今日队列包含该题 |
| 第一次答对 | 通过，仍处于待复习状态 |
| 第二次答对 | 通过，自动标记为已掌握 |
| 已掌握错题本 | 通过，包含该题 |
| 待复习错题本 | 通过，数量为 0 |
