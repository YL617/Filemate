# FileMate 2026 年 9 月竞赛优化实施计划

> 目标：在不破坏现有“资料—练习—错题—计划—复习”闭环的前提下，把 FileMate 提升为可演示、可评测、可解释的本地优先多智能体学习工作台。  
> 原则：代码、真实运行记录和可复现实验是事实源；规划能力未完成前不得写成已实现。

## 1. 竞赛核心叙事

FileMate 将学生散落的数字资料转化为可追溯的学习资产，并由多个职责明确的 Agent 协作完成目标拆解、资料检索、学习训练、面试验证和安全检查。系统默认本地保存，所有高风险文件操作均需确认、可撤销、可审计。

演示主线：

```text
杂乱资料
→ 自动理解与安全整理
→ 建立带来源的个人知识库
→ Agent 按目标安排学习
→ 练习、复习与面试验证
→ 形成带证据的能力反馈
→ 动态调整下一步任务
```

## 2. 四条建设线与完成定义

### A. 多模态模拟面试

首版：

- 摄像头仅在本地预览，和麦克风分开授权。
- 语音识别记录回答时长、字速、口头语和较长停顿。
- 流畅性作为低权重参考分，占单题总分 15%；文字回答不生成该指标。
- 反馈保留原回答、分项评分和指标来源。

后续：

- 本地录像与用户主动保存；默认不录像。
- 回答时间轴和关键片段回看。
- 简历、岗位说明或竞赛申报书驱动追问。
- 两名教师或企业导师盲评，测量系统评分相关性。

验收：摄像头拒绝授权时仍可完成整场面试；关闭页面后摄像头轨道释放；语音回答产生可持久化流畅度证据；文字回答不出现虚构指标。

### B. 个性化学习伙伴

首版：

- 复用 FileMate 既有八种表情素材。
- 完成学习日、错题重练、面试评分触发表情和反馈文案。
- 每次反馈显示触发依据，例如任务名称、匹配度或最近面试分数。
- 用户最近一次真实事件在本机保存 12 小时，成长页可继续展示。

后续：

- 成长值由任务完成、错题掌握和复习坚持共同驱动。
- 解锁服装、动作和学习场景，不设置付费数值优势。
- 提醒强度、称呼、语气和动画可以关闭或调整。
- 宠物不依据面部表情猜测情绪，也不使用羞辱式连续签到机制。

验收：角色状态必须能追溯到真实学习事件；样本不足时显示“待评测”；关闭动效偏好时停止非必要动画。

### C. 六角色 Agent 与共享记忆

角色边界：

| Agent | 输入 | 输出 | 禁止行为 |
| --- | --- | --- | --- |
| 规划 Agent | 用户目标、截止日期、能力证据 | 可执行任务图 | 直接移动文件 |
| 资料 Agent | 查询、知识来源 | 引用片段、页码、置信信息 | 无来源生成结论 |
| 学习教练 Agent | 资料、错题和计划 | 练习、复习路径、讲解 | 篡改原始资料 |
| 面试 Agent | 目标方向、题库、历史表现 | 提问和难度调整 | 评价颜值、性格 |
| 评价 Agent | 回答和学习证据 | 分项评分、错因、建议 | 数据不足时编造画像 |
| 安全 Agent | 操作计划、权限和来源 | 允许、需确认或拒绝 | 绕过用户确认 |

共享记忆分层：

1. 会话记忆：当前任务上下文，可随会话结束清理。
2. 知识记忆：原始资料、分块、来源和引用。
3. 成长记忆：练习、错题、计划和面试证据。
4. 操作记忆：文件操作、授权、确认和撤销记录。

每条长期记忆至少保存：来源 ID、创建时间、用途范围、所属工作区、可见级别和删除状态。Agent 运行轨迹需要可回放，但不得记录 API Key、完整敏感原文或摄像头画面。

验收：同一任务可查看 Agent 顺序、每步输入来源和输出摘要；重启后状态可恢复；安全 Agent 可以在执行前中断高风险操作。

### D. 知识版权与安全中心

- 导入资料时声明“本人资料、已获授权、公开资料或待确认”。
- 默认本地保存；调用外部模型前展示将发送的内容范围。
- 原文件、AI 产物和引用之间保留来源关系。
- 分享前检测个人信息、受限制资料和缺失引用。
- 支持导出个人数据、删除记忆、查看操作日志。
- 外部文档内容视为不可信数据，不能提高 Agent 权限。

验收：未确认版权来源的资料不能一键公开分享；清除操作需二次确认并提供清单；删除后检索结果不再返回该来源。

## 4. 竞赛实验矩阵

| 研究问题 | 对照 | 指标 | 数据边界 |
| --- | --- | --- | --- |
| 检索是否更可靠 | 整篇截断、当前分块、增强检索 | Recall@K、引用正确率、响应时间 | 合成回归与真实匿名集分开报告 |
| 多 Agent 是否优于单 Agent | 单 Agent、六角色编排 | 任务完成率、无来源结论率、调用成本 | 保存匿名轨迹，不保存密钥和私人原文 |
| 多模态面试是否提升训练效果 | 文字训练、语音与摄像头训练 | 复练提升、人工评分相关性、完成率 | 摄像头默认不保存，参与者单独授权 |
| 学习伙伴是否促进坚持 | 普通提醒、事件驱动伙伴反馈 | 计划完成率、复习率、次日回访 | 不把小样本趋势写成因果结论 |

## 5. 评审演示的五分钟证据链

1. 导入一份包含课程任务和截止日期的真实匿名资料。
2. 展示分类、命名、日历预览以及用户确认和撤销。
3. 从资料生成知识卡和题目，答案跳回来源页。
4. 完成一道复习题，学习伙伴出现由该事件触发的个性化反馈。
5. 开启本地摄像头和语音面试，展示流畅度来源、分项评分与成长证据。
6. 展示 Agent 轨迹、安全检查和数据全部删除/导出入口。

## 6. 不进入本月阻塞范围的能力

- 颜值、情绪或性格识别。
- 默认上传或长期保存摄像头录像。
- 没有对照实验支撑的复杂图数据库和重量级 Agent 框架。
- 以签到惩罚、焦虑提醒或虚构百分比驱动用户。
- 为了展示而生成无法复现的准确率和用户增长数据。
